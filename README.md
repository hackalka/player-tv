# Player TV - Estilo Netflix

Cliente web para Telegram TV con una interfaz moderna inspirada en Netflix.

## Estructura del Proyecto

- `index.html`: Estructura principal de la aplicación.
- `style.css`: Estilos y animaciones (Netflix-style).
- `script.js`: Lógica de la aplicación y manejo de la UI.
- `config.js`: Configuración de la API de Telegram y ajustes de la aplicación.
- `assets/`: Directorio para imágenes y recursos estáticos.

## Configuración

Para que la aplicación funcione correctamente, debes configurar tus credenciales de Telegram en `config.js`.

## Características

- Hero Banner (Billboard) dinámico.
- Filas de contenido scrolleables horizontalmente.
- Modal de reproducción integrado.
- Sistema de búsqueda.
- Diseño responsivo.

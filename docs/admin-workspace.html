Ajustes que se aplican a la aplicación

Guarda cada ajuste desde el formulario superior. El área y la clave forman el nombre completo del ajuste. El valor debe ser JSON válido.

player.theme · color hexadecimal del reproductor"#3ee65c"
player.volume · volumen inicial entre 0 y 10.8
player.autoplay · reproducción automáticatrue
player.pip · imagen en imagentrue
player.screenshot · capturastrue
player.playbackRate · velocidadtrue
player.aspectRatio · selector de proporcióntrue
ui.accentColor · color principal"#e50914"
ui.backgroundColor · fondo principal"#090d16"
ui.cardRadius · radio de tarjeta, 0–3212
ui.fontFamily · familia tipográfica CSS"Arial, sans-serif"

Los cambios se leen al iniciar/cargar el catálogo y al abrir el reproductor. Recarga la aplicación para ver los ajustes visuales.
